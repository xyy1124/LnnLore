# PocketInn 特别版

> **特别版说明**：本目录为 [PocketInn](https://github.com/adoretes/PocketInn)（上游开源项目）的特别版改造，基于上游 `main` 分支源码，在保留全部原有功能的基础上新增以下特定功能：
>
> 1. **强制思维链**：角色回复前必须先按【强制思维模式】模板输出 `<think>...</think>` 思维链（12 步思考 + 附加思考框架）；模板声明为最高优先级系统指令（优先于角色卡、世界书、预设，不可被覆盖）；流式输出以 200~300 token 为界限检查格式，不合规即自动"退回/摧毁"重新生成，并逐级追加更加强制的最高优先级指令，循环直到思维链正确为止（发送键可随时变为停止键终止循环；为防模型始终不合规时无限消耗，自动重试上限为 10 次，超过后停止并提示）。
> 2. **思维链约束开关**：设置页 → 聊天显示 → "思维链约束"，可随时开启/关闭该约束（默认开启；关闭后按普通聊天处理，不注入模板、不校验）。
> 3. **瞬时错误自动重试**：服务端繁忙（HTTP 503/429/5xx）时自动等待重试（最多 3 次，退避 2/4/6 秒），不再直接报错。
> 4. **默认预设可删除**：设置 → 角色与设定 → 预设管理，内置"默认预设"可直接删除，删除后自动使用你自己保存的预设（可设立唯一预设）。
> 5. **快捷指令（分类 + 询问）**：聊天输入框**发送键左侧 + 图标**打开分类菜单——"直接发送"（继续/下一场景等，点击即发）与"询问后发送"（时间流逝/旁白/详细描写/摄像机视角等，先输入补充内容再发送）；指令与提示词、类型可在 设置 → 角色与设定 → 快捷指令 中自由增删改。
> 6. **文本样式预设**：设置 → 通用设置 → 主题配置 → 文本样式，一键应用"自动优化"（跟随主题色生成协调配色，深色主题使用高亮色系）或"高对比经典 / 暖色柔和 / 冷色清新"预设方案。
> 7. **思维链模板可配置**：设置 → 角色与设定 → 思维链约束，可查看/修改 12 步思维链模板，创建多套方案并选择一套生效；校验采用内容启发式（`<think>` 闭合 + 内容 ≥80 字），避免误退回；模板注入在角色卡之前，且每次回复都附带尾部提醒。
> 8. **键盘安全编辑面板**：快捷指令 / 思维链方案 / 用户设定的编辑界面改为底部弹出式，输入法弹出时取消/保存按钮不再跳动。
> 9. **角色 AI 通读介绍**：设置 → 角色与设定 → 角色列表，每个角色卡片右下角箭头可让 AI 通读角色卡与配套世界书，生成**深度解读**（提炼动机/冲突/隐藏细节，非照本宣科）并支持 **Markdown 渲染**；右上角齿轮可单独选择介绍所用的 AI 模型。
> 10. **思维链 reasoning 兼容**：DeepSeek R1/V3 等 CoT 抑制模型把思考输出在 reasoning 字段（正文无 `<think>` 标签）——此类模型的 reasoning 长思考视为合规，不再误退回。
> 11. **群聊**：角色列表右上角"群聊"图标可创建多角色群聊，成员按顺序轮流回复；每条消息显示发言人角色名。
> 12. **调色板扩充**：主题调色板新增 16 个柔和舒适色（莫兰迪/马卡龙风），"自动优化"预设按主题色自动匹配协调的柔和色搭配。
> 13. **输出时界面不动**：AI 流式输出期间及结束后，聊天界面视口完全保持原位，不自动滚动。
> 14. **版本检查与更新日志**：设置 → 关于 → 检查更新——启动自动检查 GitHub 发布的新版本并提示（发布仓库可配置，默认上游）；关于页更新日志已包含特别版说明。版本号：**1.4.0-special.5**（差异化版本，versionCode 60）。

PocketInn 是一个基于 Flutter 开发的 AI 聊天应用，偏向角色扮演和沉浸式对话体验，兼容 SillyTavern 的角色卡、世界书、预设等数据格式。

## 功能

- 支持配置多种 AI 接口
- 支持角色聊天与预设管理
- 支持世界书等基础设定功能
- 支持导入本地角色资源

## 开发环境

- Flutter
- Dart 3
