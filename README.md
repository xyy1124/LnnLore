# LnnLore（PocketInn 特别版）

> **基于开源项目 [PocketInn](https://github.com/adoretes/PocketInn)（上游）深度改造的 AI 聊天应用**，兼容 SillyTavern 的角色卡、世界书、预设等数据格式。

**LnnLore** 是一个基于 Flutter 开发的 AI 聊天应用，偏向角色扮演与沉浸式对话体验。它保留了上游 PocketInn 的全部功能，并在此基础上加入了**角色状态面板系统**、**强制思维链**、**群聊**等大量增强功能。

> 🤖 **AI 辅助说明**：本项目的新增代码与调试由 **DeepSeek AI** 辅助完成——按需求逐版迭代（v1 至 v54 均在 AI 对话中完成设计与实现、测试与发布），这是人类需求与 AI 协作打磨的成果。

## ✨ 特别版功能

### 🎴 角色状态系统（Tracker）

- **角色卡状态声明**：角色卡通过 `data.extensions.tracker` 声明状态字段（数值 / 字符串）、初始值与显示顺序，每张卡定义自己的"状态面板"
- **HTML 状态面板**：卡片可自定义 HTML/CSS 面板模板（深色卡片、表格、图标、进度条等），App 原生渲染——不同卡片显示各自的面板样式
- **确定性旁白修改**：发送时本地解析 `（烙印值+10）`、`（体力=35）`、`烙印值提高40%` 等旁白语法并立即落地（数值自动 clamp 到 schema 的 min/max），不依赖模型输出
- **模型状态协议**：模型每轮通过 JSON patch（`{"patch":{"set":{},"add":{}}}`）更新状态，App 负责校验、持久化与渲染
- **消息级状态快照**：每条消息保存该时刻的状态快照，历史消息显示"当时"的状态，不随后续轮次漂移
- **状态面板折叠**：面板标题栏可点击收起 / 展开

### 🧠 强制思维链

- 角色回复前必须输出 `<think>...</think>` 思维链（12 步思考模板，可在设置中自定义、多方案切换）
- 流式输出自动校验格式，不合规自动"退回 / 摧毁"重新生成（上限 10 次防无限消耗）
- 兼容 DeepSeek R1/V3 等 CoT 抑制模型（reasoning 字段长思考视为合规）

### 👥 群聊

- 创建多角色群聊，成员按顺序轮流回复，每条消息显示发言人角色名，人设互不串台

### ⚡ 其他增强

- **瞬时错误自动重试**：服务端繁忙（HTTP 503 / 429 / 5xx）时退避重试（最多 3 次），不再直接报错
- **默认预设可删除**：内置"默认预设"可直接删除，删除后自动使用自定义预设
- **快捷指令系统**：发送键左侧图标打开分类菜单——"直接发送"与"询问后发送"（时间流逝 / 旁白 / 详细描写 / 摄像机视角等），指令内容可自由增删改
- **文本样式预设**：一键应用"自动优化"（跟随主题色生成协调配色）或高对比 / 暖色柔和 / 冷色清新方案
- **键盘安全编辑面板**：快捷指令 / 思维链方案 / 用户设定改为底部弹出式编辑，输入法弹出时按钮不再跳动
- **角色 AI 通读介绍**：让 AI 通读角色卡与配套世界书，生成深度解读（提炼动机 / 冲突 / 隐藏细节），支持 Markdown 渲染，可选模型
- **调色板扩充**：新增 16 个莫兰迪 / 马卡龙柔和色，自动优化预设按主题色匹配
- **输出时界面不动**：AI 流式输出期间及结束后，聊天视口保持原位，不自动滚动
- **版本检查与更新日志**：启动自动检查 GitHub 发布的新版本并提示，关于页含完整更新日志

## 🚀 开发环境

- Flutter / Dart 3
- 构建：`flutter run`（调试） / `flutter build apk --release`（Android 安装包）

## 🧩 数据兼容

- 兼容 SillyTavern 角色卡（含 Chara Card V2 扩展）、世界书、预设等数据格式
- 支持导入本地角色资源
